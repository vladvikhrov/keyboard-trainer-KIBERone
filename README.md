# Клавиатурный турнир — тренажёр скорости печати

Тренажёр слепой печати на русском языке для детей 10–12 лет. Разработан для занятий в кибершколе KIBERONE.

Приложение представляет собой один HTML-файл. Оно не требует установки, регистрации, интернета и сервера: файл открывается локально в браузере и полностью работает офлайн. На каждом компьютере тренажёр запускается независимо, поэтому его можно одновременно использовать всем классом.

## Возможности

- Три уровня сложности: короткие слова, простые предложения, тексты о веб-разработке, искусственном интеллекте и безопасности в сети.
- Таймер на 30, 60 или 120 секунд. Отсчёт начинается с первой нажатой буквы, а не с момента открытия страницы.
- Посимвольная подсветка: набранное верно выделяется бирюзовым, текущий символ — жёлтым, ошибка — розовым.
- Ошибка блокирует ввод. Курсор не двигается дальше, пока не нажата правильная клавиша, поэтому ученик не «проскакивает» опечатки.
- Автоматическая подгрузка следующего случайного текста, если предыдущий закончился раньше времени. Таймер при этом продолжает идти, статистика суммируется.
- Экран результатов: скорость в знаках в минуту, точность в процентах, количество верно набранных символов и комментарий по итогу.
- Загрузка собственного файла с текстами без пересборки приложения.
- Адаптивная вёрстка и поддержка экранных клавиатур планшетов.

## Запуск

Скачайте `typing-trainer.html` и откройте его двойным щелчком в любом современном браузере (Chrome, Edge, Firefox, Safari). Подключение к сети не требуется.

Для класса удобны два варианта:

1. Скопировать файл на каждый компьютер, например на рабочий стол.
2. Положить файл в общую сетевую папку и открывать его оттуда. Ученики работают независимо, данные никуда не передаются и не сохраняются.

Опубликовать тренажёр можно через GitHub Pages: в настройках репозитория раздел Pages, источник — ветка `main`, папка `/root`. После публикации файл будет доступен по адресу вида `https://<пользователь>.github.io/<репозиторий>/typing-trainer.html`.

## Как пользоваться

1. Выберите уровень сложности кнопками в верхней панели.
2. Щёлкните по белой карточке с текстом, чтобы поле приняло ввод.
3. Начинайте печатать. Таймер стартует после первого символа.
4. При ошибке найдите нужную букву: до правильного нажатия курсор стоит на месте.
5. По истечении времени откроется экран результатов.

Кнопки управления:

- «Начать заново» — повторить попытку на том же тексте.
- «Новый текст» — взять другой случайный текст того же уровня.
- «Время» — переключить длительность попытки между 30, 60 и 120 секундами.

Смена уровня, перезапуск и смена текста сбрасывают таймер и статистику.

## Как дополнять тексты

Файл `texts.txt` рассчитан на редактирование преподавателем. Формат:

```
# ЛЁГКИЙ

кот дом сыр лес мяч рука нога небо море сад

день ночь вода хлеб стол стул окно дверь снег дождь

# СРЕДНИЙ

Компьютер помогает нам решать сложные задачи.

# СЛОЖНЫЙ

Алгоритм — это точная последовательность шагов, которая приводит к результату.
```

Правила:

- Один абзац равен одному заданию. Абзацы разделяются пустой строкой.
- Строки `# ЛЁГКИЙ`, `# СРЕДНИЙ`, `# СЛОЖНЫЙ` задают уровень для всего, что идёт ниже, до следующего заголовка.
- Любая другая строка, начинающаяся с `#`, считается комментарием и в тренажёр не попадает.
- Кодировка файла — UTF-8.
- Несколько строк подряд без пустой строки между ними склеиваются в одно задание.

Чтобы подключить свой файл, нажмите «Загрузить свои тексты (.txt)» и выберите его. Файл читается средствами браузера на самом компьютере и никуда не отправляется. После перезагрузки страницы тренажёр снова использует встроенный набор, поэтому для постоянного использования удобнее заменить содержимое блока `<script type="text/plain" id="defaultTexts">` внутри `typing-trainer.html` — формат там тот же.

## Как считается результат

- Скорость: количество верно набранных символов, делённое на длительность попытки и приведённое к минуте.
- Точность: доля верных нажатий от всех нажатий с печатаемыми символами.
- Повторные нажатия неверных клавиш учитываются в знаменателе точности, но не останавливают попытку.

Ориентиры для детей 10–12 лет: 60–120 знаков в минуту — уверенный уровень, выше 180 — высокая скорость. Точность важнее скорости: при показателе ниже 90 процентов имеет смысл печатать медленнее и ровнее.

## Технические детали

Чистые HTML, CSS и JavaScript без сборки, фреймворков и зависимостей. Внешние запросы не выполняются, данные не сохраняются ни локально, ни на сервере. Поддерживается уменьшение анимации через `prefers-reduced-motion`.
