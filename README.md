# Тренажёры клавиатуры KIBERONE

Набор офлайн-тренажёров клавиатуры на русском языке для детей 10–12 лет. Разработан для занятий в кибершколе KIBERONE.

Два тренажёра (скорость печати и горячие клавиши) и игра «Буквопад» связаны общим меню слева. Ничего не требует установки, регистрации, интернета и сервера: страницы открываются локально в браузере и полностью работают офлайн. На каждом компьютере тренажёры запускаются независимо, поэтому их можно одновременно использовать всем классом.

## Состав папки

| Файл | Назначение |
| --- | --- |
| `index.html` | Точка входа: сразу открывает тренажёр печати |

| `hotkeys.html` | Тренажёр горячих клавиш (разметка страницы) |
| `game.html` | Игра «Буквопад» (разметка страницы) |
| `styles.css` | Общие стили всех страниц |
| `common.js` | Общий код всех страниц: рекорд сессии, конфетти, раскладка ЙЦУКЕН, схема клавиатуры |
| `typing.js` | Логика тренажёра печати |
| `hotkeys.js` | Логика тренажёра горячих клавиш |
| `game.js` | Логика игры «Буквопад» |
| `texts.txt` | Редактируемый набор текстов для тренажёра печати |

Стили и логика вынесены в отдельные файлы (`styles.css`, `common.js`, `typing.js`, `hotkeys.js`, `game.js`), а разметка осталась в HTML. Все файлы связаны относительными ссылками, поэтому должны лежать рядом в одной папке.

## Запуск

Скопируйте всю папку целиком, со всеми файлами, на компьютер или в общую сетевую папку. Откройте `index.html` двойным щелчком в любом современном браузере (Chrome, Edge, Firefox, Safari) — откроется тренажёр печати. Подключение к сети не требуется.

Важно копировать файлы вместе: если `styles.css`, `common.js`, `typing.js`, `hotkeys.js` или `game.js` не окажется рядом, страница откроется без оформления или без работы кнопок.

Про `index.html`: это маленькая страница-переадресация. Любой ярлык — хоть на `index.html`, хоть на `typing-trainer.html` — ведёт на тренажёр печати, так что менять существующие ярлыки на компьютерах не нужно.

Опубликовать можно и через GitHub Pages: в настройках репозитория раздел Pages, источник — ветка `main`, папка `/root`. После публикации адрес будет вида `https://<пользователь>.github.io/<репозиторий>/`.

## Рекорд сессии

Все страницы показывают личный рекорд, пока открыта вкладка браузера. Рекорд сохраняется при переходе между страницами в той же вкладке и обнуляется после её закрытия. Ничего не пишется на диск и не передаётся никуда — это удобно и безопасно для общих компьютеров: следующий ученик открывает страницу с чистого листа.

- В тренажёре печати рекорд — лучшая скорость (знаков в минуту) за сессию.
- В тренажёре горячих клавиш рекорд — лучшая скорость (сочетаний в минуту) в режиме «Проверка». Он показан крупной яркой плашкой.
- В «Буквопаде» рекорд — больше всего пойманных букв за раунд, отдельно для каждой сложности.

## Тренажёр скорости печати

Возможности:

- Все тексты идут одним набором вперемешку — от коротких слов до предложений о веб-разработке, искусственном интеллекте и безопасности в сети.
- Таймер на 30, 60, 120 или 300 секунд. Отсчёт начинается с первой нажатой буквы.
- Посимвольная подсветка: верное — бирюзовым, текущий символ — жёлтым, ошибка — розовым.
- Ошибка блокирует ввод: курсор не двигается, пока не нажата правильная клавиша.
- Если текст закончился раньше времени, автоматически подгружается следующий, таймер продолжает идти.
- Схема клавиатуры по кнопке «Показать подсказку»: нужная клавиша подсвечивается, цвет показывает руку — бирюзовый левая, розовый правая, жёлтый пробел.
- Поддерживающие сообщения (всплывают внизу экрана, не перекрывая текст), счётчик серии без ошибок, конфетти со всплеском при завершении.
- Замены символов: длинное и среднее тире можно набрать дефисом, кавычки-ёлочки и лапки — обычной кавычкой, многоточие — точкой.

На экране результатов — два показателя: скорость (знаков в минуту) и точность.

Как пользоваться:

1. Щёлкните по белой карточке с текстом, чтобы поле приняло ввод.
2. Начинайте печатать — таймер стартует с первого символа.
3. При ошибке найдите нужную букву: до правильного нажатия курсор стоит на месте.
4. По истечении времени откроется экран результатов.

Кнопки: «Начать заново» повторяет попытку на том же тексте, «Новый текст» берёт другой случайный текст, «Время» переключает длительность (30 секунд, 1, 2 или 5 минут), «Показать подсказку» открывает схему клавиатуры. По мере роста навыка подсказку стоит прятать — слепой набор и есть главная цель.

## Тренажёр горячих клавиш

Учит сочетаниям, которые работают почти во всех программах. Все сочетания идут одним набором: простые (копировать, вставить, вырезать, отменить, вернуть, выделить всё, сохранить, найти, жирный, курсив, подчеркнуть) и продвинутые (Ctrl+Shift+Z, выделение слова, Shift+Enter, перемещение строки). В шпаргалке продвинутые отмечены звёздочкой.

Два режима:

- «Учить» — подсказка с сочетанием видна, таймера нет, можно тренироваться в своём темпе.
- «Проверка (60 сек)» — подсказка скрыта, идёт таймер, считается скорость. Именно здесь ставится рекорд сессии.

Как пользуется ученик: смотрит, какое действие нужно выполнить (например, «Копировать»), и нажимает сочетание, зажав модификатор (Ctrl, Shift или Alt). При верном нажатии задание сменится, при ошибке появится подсказка с нужным сочетанием. Кнопка «Пропустить» даёт другое задание, «Показать шпаргалку» открывает список всех сочетаний. На экране результатов — скорость (сочетаний в минуту) и точность.

Важные технические детали:

- Сочетания распознаются по физической клавише, а не по букве, поэтому тренажёр работает одинаково при русской и английской раскладке.
- Действия браузера (сохранить, найти, выделить всё) во время тренировки блокируются, чтобы не мешать.
- В список намеренно не включены сочетания с клавишами Home и End и с цифровой клавиатурой (на многих ноутбуках их нет), а также смена раскладки Alt+Shift — её нажатие тренажёр просто пропускает, ошибкой оно не считается.
- В список намеренно не включены сочетания, закрывающие или открывающие вкладки (Ctrl+W, Ctrl+T, Ctrl+N) и печать (Ctrl+P), — их перехватывает браузер, и они мешали бы занятию.

## Игра «Буквопад»

Сверху в игровом поле падают буквы. Нужно нажать клавишу с этой буквой, пока она не долетела до низа.

Правила:

- Раунд длится 90 секунд. К концу раунда буквы падают и появляются в 1,6 раза чаще и быстрее, чем в начале.
- Даётся 3 жизни. Жизнь отнимает только буква, которая долетела до низа. Если жизни закончились раньше 90 секунд, раунд завершается.
- Неверная клавиша жизнь не отнимает, но сбрасывает серию и снижает точность. Так нет смысла стучать по всем клавишам подряд.
- Если на экране две одинаковые буквы, нажатие засчитывается той, что ниже.
- Зажатая клавиша считается одним нажатием, а не очередью.

Сложность задаёт и набор букв, и скорость:

| Режим | Буквы | Падение в начале | Букв на экране |
| --- | --- | --- | --- |
| Лёгкий | средний ряд: Ф Ы В А П Р О Л Д Ж | 7 секунд | до 3 |
| Средний | средний и верхний ряд без Х и Ъ | 5 секунд | до 4 |
| Сложный | все 33 буквы | 3,6 секунды | до 6 |

На лёгком уровне под полем показана клавиатура: подсвечена клавиша для ближайшей к низу буквы, цвет показывает руку. На среднем и сложном уровнях подсказки нет.

Правила на странице спрятаны в блок «Как играть», он раскрывается по щелчку. Так игровое поле целиком помещается на экран ноутбука.

Управление: пробел или кнопка «Старт» на игровом поле начинают раунд после отсчёта 3-2-1, Esc или кнопка ⏸️ в верхней панели останавливают игру. Если ученик переключился на другую вкладку или окно, игра сама встаёт на паузу. После паузы снова идёт отсчёт.

На экране результатов: сколько букв поймано, точность (доля верных нажатий) и лучшая серия.

Важные технические детали:

- Буквы распознаются по физической клавише (как в тренажёре горячих клавиш), поэтому игра работает и при английской раскладке. Клавиша Q — это Й, клавиша A — Ф и так далее.
- Скорость падения рассчитывается по времени, а не по кадрам, поэтому на мониторах 60 Гц и 144 Гц буквы падают одинаково.
- Скорость и частоту букв для каждой сложности можно поменять в начале `game.js`, в объекте `MODES`.

## Как дополнять тексты для печати

Тексты тренажёра печати вшиты прямо в `typing-trainer.html`, поэтому страница самодостаточна. Дополнять их можно двумя способами.

Способ 1 — быстрый, через кнопку. Отредактируйте `texts.txt` в Блокноте, принесите его на нужный компьютер и нажмите в тренажёре «Загрузить свои тексты (.txt)». Файл читается браузером локально и никуда не отправляется. Действует до перезагрузки страницы.

Способ 2 — постоянный, внутри HTML. Откройте `typing-trainer.html` Блокнотом, найдите блок `<script type="text/plain" id="defaultTexts">` и отредактируйте тексты прямо в нём. Формат тот же, что в `texts.txt`.

Формат файла с текстами:

```
# ЛЁГКИЙ

кот дом сыр лес мяч рука нога небо море сад

день ночь вода хлеб стол стул окно дверь снег дождь

# СРЕДНИЙ

Компьютер помогает нам решать сложные задачи.

# СЛОЖНЫЙ

Алгоритм — это точная последовательность шагов, которая приводит к результату.
```

Правила:

- Один абзац равен одному заданию. Абзацы разделяются пустой строкой.
- Строки `# ЛЁГКИЙ`, `# СРЕДНИЙ`, `# СЛОЖНЫЙ` помогают держать файл в порядке. На сам тренажёр они больше не влияют: все тексты показываются вперемешку одним набором.
- Любая другая строка, начинающаяся с `#`, — это комментарий, в тренажёр он не попадёт.
- Кодировка файла — UTF-8.
- Длинное тире, кавычки-ёлочки и многоточие использовать можно: тренажёр принимает вместо них дефис, обычную кавычку и точку.

## Как считается результат в тренажёре печати

- Скорость: число верно набранных символов, делённое на длительность попытки и приведённое к минуте.
- Точность: доля верных нажатий от всех нажатий с печатаемыми символами.

Ориентиры для детей 10–12 лет: 60–120 знаков в минуту — уверенный уровень, выше 180 — высокая скорость. Точность важнее скорости: при показателе ниже 90 процентов имеет смысл печатать медленнее и ровнее.

## Как устроены файлы (для правок)

- `styles.css` — один файл на все страницы. Общие компоненты (меню, панель, кнопки, карточка, результаты) описаны один раз без префикса, а различия страниц заскоуплены классами `page-typing`, `page-hotkeys` и `page-game` (класс проставлен в теге `<body>` каждой страницы). Поэтому меню печати бирюзовое, горячих клавиш розовое, игры оранжевое, и правила не конфликтуют.
- Цвет кнопки задаётся классом: `teal`, `pink`, `yellow`, `orange`, `violet`, `blue` (например, `<button class="btn orange">`). Класс работает для больших кнопок `.btn`, переключателей режима `.mode` и маленьких кнопок `.toggle`. Сейчас у каждой кнопки свой цвет, чтобы их было легко различать.
- `common.js` — общий код: рекорд сессии в памяти вкладки, конфетти, форматирование времени, раскладка ЙЦУКЕН (буква по физической клавише) и схема клавиатуры. Подключается на каждой странице перед `typing.js`, `hotkeys.js` или `game.js`.
- `typing.js`, `hotkeys.js` и `game.js` — логика каждой страницы. Правки поведения делаются здесь, правки оформления — в `styles.css`, правки текста на странице — в соответствующем `.html`.
- Анимации (конфетти, всплеск, подсветка) отключаются автоматически, если в системе включён режим уменьшения движения.

## Технические детали

Чистые HTML, CSS и JavaScript без сборки, фреймворков и зависимостей. Внешние запросы не выполняются. Рекорд сессии хранится в памяти вкладки (sessionStorage) и не пишется на диск.
